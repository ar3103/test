# Европочта для Bitrix без разработки отдельного модуля

Решение реализует доставку Европочтой **без собственного модуля**, только на основе файлов в `/local/php_interface`:

- кастомный обработчик доставки;
- синхронизация отделений с API Европочты;
- выпадающий список отделений в свойстве заказа (`LIST`), без привязки к локациям Bitrix;
- удалённые на стороне Европочты отделения автоматически скрываются у вас.

## 1) Файлы

- `local/php_interface/include/sale_delivery/europost_handler.php` — обработчик службы доставки.
- `local/php_interface/include/europost_repository.php` — таблица и доступ к отделениям.
- `local/php_interface/include/europost_sync.php` — синхронизация отделений + обновление значений свойства заказа.
- `local/php_interface/include/cron/europost_sync.php` — cron-скрипт.

## 2) Подключение обработчика доставки

1. В админке: **Магазин → Настройки → Службы доставки → Добавить**.
2. Тип: **Обработчик службы доставки**.
3. Указать путь до класса `Sale\Handlers\Delivery\EuropostHandler`.
4. Добавить службу в нужные ограничения оплаты/корзины.

> В обработчике уже задан максимум веса: **200 кг**.

## 3) Тарифная сетка “за каждые 2 кг”

В файле `europost_handler.php` есть константа:

```php
private const PRICE_GRID = [
    1 => 5.00,  // 0-2 кг
    2 => 6.50,  // 2-4 кг
    3 => 8.00,  // 4-6 кг
    4 => 9.50,  // 6-8 кг
    5 => 11.00, // 8-10 кг
];
```

- шаг всегда 2 кг;
- если вес выше последнего блока в массиве — берётся последняя цена;
- если нужно, можно расширить массив до 100 блоков (до 200 кг).

## 4) Выпадающий список отделений (без локаций Bitrix)

Создайте свойство заказа:

- Код: `EUROPOST_OFFICE`
- Тип: `Список`
- Обязательное: `Да` (по желанию)

Синхронизация автоматически обновляет значения списка через `OrderPropsVariantTable`.

## 5) Синхронизация отделений и удаление неактуальных

Запуск:

```bash
php /path/to/site/local/php_interface/include/cron/europost_sync.php
```

Что делает синхронизация:

1. Забирает отделения из API Европочты.
2. Обновляет/добавляет активные отделения в `b_europost_office`.
3. Все отделения, которых нет в свежей выгрузке, помечает `ACTIVE = 'N'`.
4. В свойстве заказа удаляет варианты, которых уже нет в API.

Так вы гарантированно не показываете удалённые отделения на сайте.

## 6) Cron

Пример (каждые 3 часа):

```cron
0 */3 * * * /usr/bin/php -f /home/bitrix/www/local/php_interface/include/cron/europost_sync.php >/dev/null 2>&1
```

## 7) Важно по API

В `EuropostSyncService::API_URL` стоит примерный URL. Подставьте ваш актуальный endpoint официального API Европочты и, при необходимости, токен/заголовки.
