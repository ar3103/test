# Выгрузка заказов Bitrix в Google Sheets с двусторонней синхронизацией

Репозиторий содержит готовый PHP-класс для Bitrix, который:

- выгружает заказы в Google Sheets с полями:
  - Id
  - номер заказа
  - позиции заказа
  - вес
  - скидка
  - сумма заказа без скидки
  - сумма заказа со скидкой
  - фамилия
  - имя
  - отчество
  - номер телефона
  - способ доставки
  - адрес доставки
  - номер отделения
- читает изменения из таблицы и обновляет заказ в Bitrix.

## Файлы

- `local/php_interface/lib/OrderGoogleSheetSync.php` — логика синхронизации в обе стороны.
- `local/php_interface/init.php` — пример агента Bitrix для запуска синхронизации.
- `composer.json` — зависимость `google/apiclient`.

## Установка

1. Установить пакет Google API Client:
   ```bash
   composer install
   ```
2. Создать сервисный аккаунт в Google Cloud, включить Google Sheets API.
3. Выдать доступ к таблице e-mail сервисного аккаунта.
4. Сохранить JSON-ключ в:
   - `/local/secrets/google-service-account.json`
5. В `local/php_interface/init.php` указать `SPREADSHEET_ID`.

## Настройка свойств заказа

В классе `OrderGoogleSheetSync` есть `PROPERTY_CODES`.
Подставьте реальные коды свойств вашего заказа в Bitrix:

- `LAST_NAME`
- `NAME`
- `SECOND_NAME`
- `PHONE`
- `ADDRESS`
- `BRANCH_NUMBER`

## Как работает синхронизация

Метод `sync()` делает две операции:

1. `exportOrdersToSheet()` — полная выгрузка текущих заказов Bitrix в лист `Orders`.
2. `importSheetChangesToBitrix()` — чтение строк из таблицы и обновление полей заказа в Bitrix.

Таким образом изменения в таблице (ФИО, телефон, доставка, адрес, номер отделения) применяются обратно в Bitrix.

## Рекомендации по запуску

- Запускать агент каждые 5–10 минут.
- Для большого количества заказов добавить фильтр по дате изменения/статусу.
- Перед продом сделать тест на копии проекта.
