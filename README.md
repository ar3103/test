# Bitrix пакет автоматизации рассылок (многосайтность)

Готовый пакет для Bitrix с поддержкой:

- еженедельных рассылок по статьям блога за последние 7 дней (через модуль `sender` + почтовые события);
- триггерных писем после посещения страниц (брошенная корзина, вебинар);
- автоответа после отправки формы заявки;
- реактивационных рассылок клиентам, которые давно не обращались;
- коротких ссылок на форму отзыва + логирования переходов;
- многоканальных кампаний: Email + SMS + Telegram;
- многосайтности: отдельные обработчики и конфиг для каждого сайта;
- базовой аналитики: open rate / CTR / bounce, логи переходов.

## Структура

- `local/php_interface/init.php` — подключение обработчика, регистрация агентов.
- `local/lib/Mailing/*` — сервисы автоматизации.
- `local/agents/mailing_agents.php` — агентные точки входа.
- `local/sites/<site_id>/mailing.php` — site-specific обработчик и ID рассылок.

## Настройка

1. Включите модули Bitrix: `iblock`, `sender`, `main` (и при необходимости `sale`, `crm`).
2. В каждом сайте создайте/настройте `local/sites/<site_id>/mailing.php`:
   - ID инфоблоков,
   - коды свойств,
   - ID почтовых шаблонов,
   - webhooks SMS/Telegram.
3. Добавьте почтовые события/шаблоны:
   - `BLOG_WEEKLY_DIGEST`
   - `FORM_THANK_YOU`
   - `REENGAGEMENT`
   - `TRIGGER_PAGE_VISIT`
   - `REPEAT_REQUEST_REPLY`
4. Добавьте агенты (или через cron):
   - `\Local\Mailing\Agents::runWeeklyDigestAgent();`
   - `\Local\Mailing\Agents::runInactiveUsersAgent();`
   - `\Local\Mailing\Agents::runAbandonedCartAgent();`

## Как определяется «с какого момента начинать рассылку»

Пакет хранит технические отметки в `b_option`:

- `last_weekly_digest_at_<SITE_ID>` — когда последний раз отправляли дайджест.
- `last_reengagement_at_<SITE_ID>` — когда последний раз запускали реактивацию.

При первом запуске:

- можно выбрать режим «сейчас» (не отправлять старые материалы);
- или «с 7 дней назад» (включить текущую неделю);
- или указать кастомную дату в опции вручную.

## A/B тесты и сегменты

В `ABTestingService` можно передавать 2 варианта темы/контента.
Сегментация задаётся фильтрами по пользовательским полям/истории активности.

## Короткие ссылки

Сервис `ShortLinkService` генерирует код, сохраняет связь `код -> URL + контакт`,
учитывает клики и последний переход.

Эндпоинт перехода:

`/local/tools/short-link.php?code=XXXXXX`

## Многоканальные кампании

`MultiChannelCampaignService`:

- Email — через `CEvent::Send`;
- SMS — через HTTP webhook провайдера;
- Telegram — через Bot API.

Порядок по умолчанию:

1. Email сразу;
2. SMS через 1 день;
3. Telegram напоминание через 2 дня.

## Отчётность

`AnalyticsService` агрегирует:

- отправки,
- открытия,
- клики,
- bounce,
- CTR / Open Rate.

Можно выгружать в CRM/кастомный отчёт.
